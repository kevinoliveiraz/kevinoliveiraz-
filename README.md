# Olá, eu sou Kevin Cardoso

## Desenvolvimento Web • Automação • Infraestrutura 

Estou construindo minha carreira em desenvolvimento e automação, unindo programação, visão de processos e conhecimento prático sobre o ambiente onde as aplicações funcionam.

Minha trajetória começou na Administração e ganhou uma nova direção no Hospital São Paulo. Ao observar processos manuais e informações espalhadas, percebi que poderia usar tecnologia para criar soluções mais simples para quem executa essas tarefas todos os dias.

Foi assim que desenvolvi projetos como o **HSP Localiza**, uma ferramenta interna para facilitar o acesso a informações do hospital, e automações em **Google Sheets com Apps Script** para validar dados, reduzir tarefas manuais e apoiar controles operacionais.

Atualmente, estudo **Desenvolvimento Front-End no Instituto PROA**, pelo projeto Transforme-se, realizado em parceria com a Serasa Experian. Continuo aprofundando meus conhecimentos em JavaScript, desenvolvimento web, automação e banco de dados.

Também possuo uma base prática em Linux, Windows, terminal, hardware e diagnóstico de sistemas. Esse conhecimento complementa meu trabalho como desenvolvedor, pois me permite entender o ambiente onde o código roda, configurar ferramentas e investigar problemas técnicos com mais autonomia.

Gosto de entender como um processo funciona, identificar onde ele pode melhorar e transformar esse conhecimento em uma ferramenta útil, clara e fácil de utilizar.
